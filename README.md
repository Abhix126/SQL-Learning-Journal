
# SQL Daily Practice

A structured daily SQL learning journey covering PostgreSQL fundamentals to advanced concepts, with theory, practical queries, datasets, and documented execution results.

## Learning Environment

- PostgreSQL 18
- SQLite
- pgAdmin 4
- DB Browser for SQLite
- Python

## Daily Practice

Each session includes:

- 5 theoretical questions with explanations
- 5 practical SQL challenges
- CSV datasets and SQL scripts
- Query solutions with execution screenshots
- Notes on mistakes and key learnings

## Repository Structure

- `D1_141026(WED)/` — Day 1: SQL Fundamentals
- `D2_151026(THU)/` — Day 2
- `D3_161026(FRI)/` — Day 3
- `D4_171026(SAT)/` — Day 4
- `docs/` — Templates, prompts, and utilities

## Goal

Develop strong SQL fundamentals and practical database skills for Python backend development.
