## Session Notes

**Concepts Practiced:** SELECT, WHERE, DISTINCT, ORDER BY, LIMIT

### Additional Notes

- `--` marks a SQL comment; remove it to execute the query.
- Always verify the correct table name (`employees` vs `employee`).
- `ORDER BY` supports multiple columns with different sorting directions.
- Use `ORDER BY salary DESC, emp_id ASC` to break salary ties consistently.
- Combine `ORDER BY` with `LIMIT` for predictable Top-N results.
